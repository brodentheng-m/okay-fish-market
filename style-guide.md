# Style Guide — Modern Site

> **STRICT DESIGN RULE: Never generate purple gradients or use purple/indigo
> utility classes. Adhere strictly to the defined minimalist color scheme.**

This file is the design contract for this project. Any AI agent (OpenCode,
Claude Code, Cursor, etc.) working in this repository MUST follow it.

---

## 1. The Palette (the only colors that exist)

| Role        | Tailwind class   | Hex       | Notes                              |
|-------------|------------------|-----------|------------------------------------|
| Surface     | `white`          | `#ffffff` | Crisp white page background        |
| Ink (text)  | `slate-900`      | `#0f172a` | Primary text                       |
| Ink (soft)  | `slate-600`      | `#475569` | Secondary text                     |
| Neutrals    | `slate-*`        | —         | Borders (`slate-100/200`), muted bg (`slate-50`) |
| Accent      | `emerald-600`    | `#059669` | Primary accent: buttons, links, highlights |
| Accent soft | `emerald-500`    | `#10b981` | Hover state, small dots, svg icons |
| Accent deep | `emerald-700`    | `#047857` | Hover/strong state, deep gradient stop |

Full slate and emerald families (`-50` through `-950`) are available.
Prefer `surface` / `ink` / `ink-soft` / `accent` / `accent-ft` / `accent-dk`
semantic tokens (defined in `src/input.css`) or the slate/emerald utilities.

## 2. Forbidden

- **Any** purple, violet, indigo, or fuchsia color — utility classes,
  hex codes, CSS variables, gradients, shadows, borders, anything.
- Purple gradients in any direction or combination.
- Importing new palettes that add these hues.

### Hard enforcement (how this is guaranteed)

In `src/input.css` the three forbidden families are **remapped**:

- `purple-*` → emerald values (same shade number)
- `violet-*` → emerald values (same shade number)
- `indigo-*` → slate values (same shade number)

So even if an agent writes `bg-purple-500` or `from-violet-600 to-indigo-800`,
the compiled CSS renders on-palette (emerald/slate). Purple output is
physically impossible in `dist/output.css`.

Quick verify after a build (values must be emerald/slate, never purple):

```bash
grep -oE -- '--color-(purple|violet|indigo)-(500|600):#[0-9a-f]+' dist/output.css
# Expect only emerald/slate hexes, e.g. --color-purple-500:#10b981 (emerald)

grep -cE '#(a855f7|9333ea|7e22ce|8b5cf6|7c3aed|6d28d9|6366f1|4f46e5|4338ca)' dist/output.css
# Expect 0 — no purple/violet/indigo hex value anywhere in the build
```

## 3. Gradients (the only allowed gradient policy)

| Use case                | Allowed classes                          |
|-------------------------|------------------------------------------|
| Hero / page wash        | `bg-linear-to-b from-slate-50 to-white`  |
| CTA panel (brand)       | `bg-linear-to-br from-emerald-600 to-emerald-700` |
| Subtle tint             | `from-emerald-50 to-white`               |

Tailwind v4 syntax is `bg-linear-to-*`; the legacy `bg-gradient-to-*` alias
still compiles. Never add a third hue to a gradient.

## 4. Typography

- Headings: **Playfair Display** (bold serif) — the classic, sharp serif that
  carries deep history, trust, and family ownership. Apply with the
  `font-display` utility (loaded: weights 600/700/800).
- Body: **Inter** (regular 400, medium 500) — clean, modern, readable; the
  default `font-sans` (persistent built-in weights: 400/500/600).
- Headings: `font-display font-bold tracking-tight text-slate-900`.
- Body: `text-slate-600`, max readable width `max-w-2xl`.
- Eyebrow labels: `text-sm font-semibold uppercase tracking-widest text-emerald-600`.
- Fonts load from Google Fonts via `<link>` in the `index.html` head
  (preconnected, `display=swap`). Do NOT add extra families/weights without
  approval.

## 5. Shape, Shadow, Spacing

- Radius: `rounded-lg` (buttons/inputs), `rounded-xl` (cards), `rounded-2xl` (panels).
- Shadows: `shadow-sm` only. Muted `border-slate-100` / `border-slate-200` borders.
- Vertical rhythm: section padding `py-20`/`py-24`; grid gap `gap-6`.
- Focus rings: `focus:ring-2 focus:ring-emerald-500/20`.

## 6. Conventions for agents

1. Utility-first; do not write custom CSS — extend `@theme` in `src/input.css` if a token is needed.
2. `dist/` is generated by `npm run build` — never edit or hand-write it.
3. Mobile-first: design at 375px, elevate with `sm:`/`md:`/`lg:` breakpoints.
4. Every new color used must come from the palette above.
5. If a purple/violet/indigo class appears in any diff, replace it with the
   slate or emerald equivalent before submitting.
